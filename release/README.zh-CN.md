# Resource Timeline 使用说明

## 直接运行

无需安装 MSI。双击 `Resource Timeline Portable.exe` 即可打开本地管理窗口。

管理窗口也可以通过以下方式重新打开：

- 再次运行便携版或已安装的软件；
- 左键单击系统托盘中的 Resource Timeline 图标；
- 右键托盘图标并选择 `Open Resource Timeline`。

关闭管理窗口或选择 `Hide window (keep collecting)` 不会停止采集。只有托盘菜单中的 `Stop collection and exit` 才会完全退出并停止采集。

开机自动启动默认开启。Windows 登录后会使用 `--background` 仅启动采集器和托盘，不显示管理窗口；再次运行便携版即可打开同一个后台进程的管理窗口。

## 安装版

- `Resource Timeline Setup.exe`：NSIS 安装包，建议普通使用选择此版本。
- `Resource Timeline.msi`：MSI 安装包，适合需要 MSI 部署的场景。

`release` 中的交付文件名不再携带版本号；实际软件版本显示在应用左侧栏中。
当前便携版、NSIS Setup 和 MSI 已统一更新为 0.3.2。

安装版会提供稳定的安装路径、开始菜单入口和卸载支持。开启“Start with Windows”后，Windows 登录时只启动后台采集器和托盘，不自动打开管理窗口。

## 管理功能

在 `Settings` 页面可以：

- 暂停或恢复后台采集；
- 设置前台应用检查频率；
- 设置系统资源采样频率；
- 设置 idle 判定时间；
- 设置原始系统样本保留天数；
- 控制是否随 Windows 启动；
- 查看本地数据库位置和大小。
- 在 English 和简体中文之间切换界面语言。

系统资源采样的 5、10、30、60 秒选项会分别说明准确性、短生命周期进程覆盖、后台开销和数据库增长的取舍。

“今日概览”“时间线”和“系统资源”会分别按本页的数据来源限制可选日期；无数据日期和未来日期会置灰且无法点击。三个页面的日期状态相互独立，切换一页的日期不会改变其他页面。“显示空闲时间”始终可用并显示当天累计时长；尚未达到空闲阈值时显示 0 秒，采集到新数据后自动刷新。

正式版启动时不会额外显示黑色控制台窗口。

## 查看高占用时刻

在“系统资源”页面点击曲线任意位置，应用会自动选中最近的真实采样点、标明该点是否有应用明细，并自动定位到详情。同一可执行文件的多个进程会合并；曾作为前台出现的应用在运行时会持续保留，同时快照还会保留 CPU、内存和进程 I/O 各前 5 名应用。

侧栏中的“应用资源”是独立页面，可以先以微信、QQ、ChatGPT 等应用为节点，再独立选择单日、近 7 天、近 30 天或起止日期，查看 CPU、内存和 I/O 历史。相同进程名的历史安装版本会合并为一个应用节点，例如 WindowsApps 中多个版本目录下的 `ChatGPT.exe` 不再重复显示。系统资源悬浮提示中的磁盘数据会自动使用 KB/MB/GB 每秒单位。

系统磁盘曲线是物理磁盘总量；应用明细中的进程 I/O 包含 Windows 报告的全部读写 I/O，二者口径不同。旧版本已经采集的系统样本没有应用快照，会明确显示“无应用资源快照”；更新后新采集的样本才有明细。

所有数据只保存在当前 Windows 用户的本地数据目录，不上传网络。数据库会无损升级到 schema v6：v5 修复旧版在 5/10 秒前台检查频率下产生的规律性错误断点，v6 持久保存默认开启的 Windows 自启动偏好；程序会把包含空格的便携版自启路径规范化为带引号命令。安装、卸载或删除项目构建缓存都不会自动删除该数据库。
